# 💳 Fraud Detection System (Real-Time ML Web App)

A real-time fraud detection system that analyzes banking transactions using Machine Learning and displays results through a modern web dashboard.

---

## 🚀 Features

- 🔐 Login system (demo authentication)
- 📊 Interactive dashboard
- 💡 Real-time fraud detection
- 📈 Live risk score graph
- 🥧 Fraud vs Safe distribution chart
- ⚡ Fast API-based prediction
- 🌐 Fully deployed (Frontend + Backend)

---

## 🧠 How It Works

1. User enters transaction details:
   - Amount
   - Transactions per hour
   - Hour of transaction
   - Location (IN / OUT)

2. Frontend sends request to backend API

3. Machine Learning model:
   - Analyzes transaction
   - Calculates risk score
   - Classifies as SAFE or FRAUD
   - Generates reasons

4. Results displayed instantly on dashboard

---

## 🏗️ Architecture

Frontend (Vercel) → Backend API (Render) → ML Model → Response
